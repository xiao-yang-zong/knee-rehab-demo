# RehabGo（康复Go）· 膝关节居家训练辅助 demo

手机网页 demo：用户把手机放在身体侧面，跟着语音提示做膝关节训练动作。网页在本机识别姿态、计算膝角并计数，训练后用“疼痛红绿灯”给出继续 / 减量 / 停止的建议，并记录每次的最大角度。

> RehabGo 仅提供居家训练参考和动作反馈，不替代医生的诊断与处置建议。动作参数经 1 位康复治疗师初步核实。

## 功能（v0.8）

- 第一次使用：欢迎页确认免责声明和医生许可 → 我的情况（4 个问题，一题一屏）→ 生成今天的训练计划
- 今天：计划和完成进度，一个“开始训练”按钮
- 训练前确认（底部弹出）：疼痛 0–10、红旗症状拦截
- 动作准备：示意动画、步骤、手机摆放、拍哪条腿、注意事项
- 训练中（全屏）：MediaPipe Pose 本地识别 → 膝角 → 状态机计数 → 语音，大号次数和保持圆环
- 训练后：三档感受（不疼 / 有点疼 / 很疼）→ 下一个动作或今天完成
- 记录：连续天数、7 天统计、角度变化、历史、训练摘要（复制发给康复师）、设置与清除数据
- 摄像头画面只在本机处理，不上传、不保存；记录只存在本机浏览器

## 快速开始

```bash
npm test                # 全部单元测试
python3 -m http.server 8080   # 本地预览：http://localhost:8080
```

- 摄像头只能在 HTTPS 或 localhost 下使用，不要直接双击 `index.html`。
- 改动作标准、文案、安全规则：只改 `config/` 里的 JSON。
- 部署：纯静态网站，整个目录上传到 GitHub Pages 即可（`_backup/`、`_dist/` 已在 .gitignore 中）。

完整的项目背景、技术决策见 [PROJECT.md](PROJECT.md)。
